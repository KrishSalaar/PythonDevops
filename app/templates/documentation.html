AWS Account Setup

  1. Use your existing AWS Account or create a new account with appropriate credentials
  2. Create 2 new instances of type t3.medium since the jenkins, docker config would be heavy for a free tier instance
  3. Name 2 instances as Worker Server and Master Server

Jenkins Configuration

  1. Install required Jenkins plugins:
    • AWS Integration
    • Docker Pipeline
    • Kubernetes Continuous Deploy
    • AWS Credentials
  2. Configure Jenkins credentials for AWS, Docker Registry, and Kubernetes.
  3. Set up Jenkins agents with necessary tools installed.
  4. Here the Master Server will consist Jenkins
  5. The Worker Server will consist Java and Docker

The following Commands will be used against Master Server

  1. For this to be done we should connect with our Master Server from the AWS Console

Add the Jenkins repo using the following command:

 sudo wget -O /etc/yum.repos.d/jenkins.repo \
    https://pkg.jenkins.io/redhat-stable/jenkins.repo

Import a key file from Jenkins-CI to enable installation from the package: 

 sudo rpm --import https://pkg.jenkins.io/redhat-stable/jenkins.io-2023.key
 sudo yum upgrade

Install Java:

 sudo yum install java-17-amazon-corretto -y

Install Jenkins:

 sudo yum install jenkins -y

Enable and Start the Jenkins Server:

 sudo systemctl enable jenkins 
 sudo systemctl start jenkins

Check the status of the Jenkins Service using the below command 

sudo systemctl status jenkins

The following commands will be used against Worker Server

Install Java:

 sudo yum install java-17-amazon-corretto -y

AWS EKS Cluster Setup

  1. Create an EKS cluster using eksctl or AWS Management Console.
  2. Configure IAM roles and policies for EKS.
  3. Set up worker nodes with appropriate instance types.
  4. Select t3.medium instance types to avoid huge costs
  5. Configure security groups and networking.
{% endif %} {% if step.id == 5 %}

Containerizing the Python Application

  1. Create a Dockerfile for the Python application.
  2. Define multi-stage builds for efficiency.
  3. Implement best practices for container security.

The below is the docker file for the application

#Base Image
FROM python:3.9-slim

#Set working dir
WORKDIR /app

#Copy in the requirements
COPY requirements.txt .

#install requirements
RUN pip install -r requirements.txt

#Sources files
COPY . .

#Expose port
EXPOSE 5000

#Start server
CMD ["python3", "run.py"]

CI/CD Pipeline Implementation

  1. Create a Jenkinsfile with complete CI/CD pipeline.
  2. Implement stages for Repo Checkout,Code Building, Docker Build, Docker Push, Kubernetes deployment.

The Following is the build script

Important Steps to consider

  1. Update the Repository Name, Branch according to your repo
  2. Update the Docker Stage which has been created using Docker Hub with your own
  3. Update your EKS Cluster name which has been mentioned in the AWS 

                pipeline {
    agent {
        label 'worker'
    }
    environment {
        dockerhub = credentials('dockerhub')
        awscred = credentials('awscredentials')
    }
    stages {
        stage('Checkout') {
            steps {
                checkout scmGit(branches: [[name: '']], extensions: [], userRemoteConfigs: [[url: 'Repo Link']])
            }
        }
        stage('Code Build Stage'){
            steps {
                sh 'sudo yum install -y pip'
                sh 'pip install -r requirements.txt'
            }
        }
        stage('docker build'){
            steps {
                sh 'docker -v'
                sh 'docker build -t docker_build_name .'
            }
        }
        stage('dockerPush')
        {
            steps {
                sh 'echo $dockerhub_PSW | docker login -u $dockerhub_USR --password-stdin'
                sh 'docker push docker_build_name'
            }
        }
        stage('kubernetes setup'){
            steps{
                sh 'kubectl version --client'
                sh 'aws eks update-kubeconfig --region region-name --name cluster-name'
                sh 'kubectl version'
                
            }
        }
        stage('kubernetes deployment')
        {
            steps{
                sh 'kubectl apply -f Application.yaml' 
            }
        }
    }
}

Kubernetes Deployment Configuration

  1. Create Kubernetes deployment manifests.
  2. Configure service definitions.

The following will the Application.yaml for Kubernetes

apiVersion: apps/v1
kind: Deployment
metadata:
  name: project-k8s-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: project-k8s-deployment
  template:
    metadata:
      labels:
        app: project-k8s-deployment
    spec:
      containers:
      - name: project-k8s-deployment
        image: docker_image_name
        ports:
        - containerPort: 5000


---

apiVersion: v1
kind: Service
metadata:
  name: project-k8s-deployment
spec:
  type: LoadBalancer
  selector:
    app: project-k8s-deployment
  ports:
  - protocol: TCP
    port: 80
    targetPort: 5000 #container port
    nodePort: 30080
